# Discusiones activas — Wikipedia en español

Version B usability-testing prototype built with Wikimedia ProtoWiki and Wikimedia Codex.

The complete participant application source is in `prototype-source.zip`. Unzip it, enter the `prototype` directory, run `npm ci`, then `npm run dev` to edit locally. The archive excludes hosting credentials and user data.

GitHub Actions builds the source archive and publishes GitHub Pages on every push to main. To publish an update, replace the source archive and commit. Discussions come live from Spanish Wikipedia; prototype pin/subscription actions are stored locally and do not modify Wikipedia.

Upstream template: https://github.com/wikimedia/ProtoWiki
